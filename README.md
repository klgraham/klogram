# Continuous Deformation

Essay-first site for Ken Graham ([klogram](https://klogram.dev)). Source of this repository is the site; GitHub Actions publishes it to GitHub Pages at <https://klogram.dev>.

```bash
quarto render
quarto preview
```

Do not publish from `klgraham.github.io`. Pages source for this repo is GitHub Actions, not a `docs/` folder or a user-site Jekyll stub.
